# 商家库存演练：三个合成眼镜款式

安装仓库已有依赖后，从项目根目录运行：

~~~sh
python -m scripts.merchant_demo --port 8010
~~~

在本机打开 http://127.0.0.1:8010 ，选眼镜款式，再点「演练按时付款」或「演练超时后付款」。用 Ctrl+C 关闭。已有 SQLite 文件或业务凭据都不会被读取或改动；每次演练只使用临时库，完成后自动清理。服务按设计仅绑定本机，不用于线上部署或真实支付。

页面逐步展示可售、已预留、已成单数量以及对账结果。按时付款时预留转成订单，库存不再扣减；超时路径释放库存后记下迟到回调，不恢复订单。两路均重放一次同一模拟事件，展示回执一致。该演练只覆盖单件预留、未发货订单，不覆盖跨进程吞吐、仓储发货和真实支付网关。

验证：python -m pytest -q tests/test_merchant_demo.py tests/test_reservations.py
